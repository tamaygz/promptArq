## Color Scheme

### Background Colors
- Main background: `RGB(30, 30, 30)` - Dark charcoal
- Header/Footer: `RGB(40, 40, 40)` - Medium gray
- Search box: `RGB(50, 50, 50)` - Light gray
- List background: `RGB(35, 35, 35)` - Slightly lighter

### Selection
- Selected item: `RGB(60, 120, 180)` - Blue accent
- Hover effect: Lighter shade of selected color

### Text Colors
- Primary text: `White` - High contrast
- Secondary text: `Light Gray (192, 192, 192)` - Medium contrast
- Muted text: `Gray (128, 128, 128)` - Low contrast

### Project Badges
- Dynamic colors based on project
- Example: `RGB(100, 150, 200)` - Soft blue
- White text on colored background

## Typography

### Fonts
- Primary: **Segoe UI** (Windows standard)
- Search box: **16pt Regular**
- Titles: **11pt Bold**
- Descriptions: **9pt Regular**
- Icons: **16pt** (emoji/unicode)

### Text Hierarchy
1. **Search input** - Largest (16pt)
2. **Prompt/Action title** - Medium (11pt Bold)
3. **Description** - Small (9pt Regular)
4. **Hint text** - Small (9pt Regular, Gray)

## Animation & Transitions

### Opening
- Fade in from 0% to 97% opacity
- Appears instantly (no slide animation)
- Focus immediately on search box

### Closing
- Fade out
- Memory cleanup

### List Scrolling
- Smooth scroll with arrow keys
- Auto-scroll to keep selection visible

### Selection Change
- Instant color change
- No animation delay

## Responsiveness

### Window Positioning
- Always centered on screen
- Stays on top of all windows
- Doesn't move with main window

### Content Overflow
- List scrolls if > 8 items
- Search box expands for long text
- Descriptions truncate with ellipsis

## Accessibility

### High Contrast
- White text on dark background
- Blue accent for selection
- Clear visual separation

### Keyboard Focus
- Visible focus indicator
- Tab order makes sense
- All actions keyboard-accessible

### Screen Reader Support (Basic)
- Form has title
- Elements have labels
- Actions have descriptions

## Best Practices

### Do's ?
- Keep search input focused
- Use arrow keys for navigation
- Read hint text at bottom
- Use Enter to confirm
- Press Esc to cancel

### Don'ts ?
- Don't use mouse (keyboard is faster)
- Don't type too fast (filter updates in real-time)
- Don't close while action is executing
- Don't resize (fixed size for consistency)

## Performance Indicators

### Loading States
- "Loading..." would appear if data fetch is slow
- Currently: Instant (data from localStorage)

### Error States
- Red border for errors
- Error message in status area
- Automatic dismiss after 3 seconds

## Customization Points

Want to customize? Edit these in `CommandPaletteForm.cs`:

1. **Colors** - `SetupCustomComponents()` method
2. **Fonts** - Font declarations in setup
3. **Sizes** - Width/Height in constructor
4. **Spacing** - Padding values
5. **Border Radius** - `CreateRoundRectRgn()` parameters

## Platform Considerations

### Windows 10/11
- Native look and feel
- DWM transparency support
- Segoe UI font (built-in)

### High DPI
- Scales automatically
- Text remains readable
- Icons may need adjustment

### Dark Mode
- Respects system theme
- Built with dark theme in mind
- Light theme not supported (yet)
